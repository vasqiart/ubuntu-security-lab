# Lab Scope

## Authorized assets

The documented work is limited to a privately controlled home lab:

- an Ubuntu Server host owned and administered by the learner;
- Docker containers running on that host;
- OWASP Juice Shop as an intentionally vulnerable training application;
- a privately controlled Kali Linux learning environment when needed;
- services installed for defensive monitoring, remote administration, and notifications.

No public IP address, local IP address, hostname, device serial number, notification topic, email address, account identifier, or authentication material is included in this repository.

## Permitted activities

- service and container health checks;
- host and application log review;
- packet-metadata observation inside the owned lab;
- controlled service stop/start tests;
- alerting and duplicate-alert suppression;
- recovery validation;
- defensive configuration review;
- documentation of findings and limitations.

## Out of scope

- systems not owned by the learner;
- targets without explicit written authorization;
- credential attacks against real accounts;
- destructive testing;
- persistence, evasion, or data exfiltration;
- publication of secrets, personal data, raw packet captures, or identifying logs.

## Scope rule

If authorization is unclear, the activity is out of scope until permission is confirmed.
