# Ethics and Authorization

All activity documented in this repository is intended for legal, defensive security learning.

The laboratory systems are owned and controlled by the learner, or are deliberately vulnerable training environments used according to their rules. The work is designed to improve detection, diagnosis, mitigation, and recovery skills.

This repository does not authorize anyone to test a third-party system. A technique that is safe in a local lab can be illegal or harmful when used against a system without permission.

## Publication rules

Before any artifact is made public:

- replace IP addresses and hostnames with generic descriptions;
- remove usernames, email addresses, notification topics, and device identifiers;
- exclude credentials, tokens, private keys, recovery keys, and session data;
- avoid raw logs or packet captures unless they have been carefully sanitized;
- describe only work that was actually completed;
- distinguish observations from assumptions and planned work.

## Responsible disclosure

If a potential vulnerability is found outside this owned lab, testing stops. Further work must follow the asset owner's published vulnerability disclosure policy and scope.
