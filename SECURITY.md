# Security Policy

This repository contains documentation for a private learning lab, not a public testing target.

Do not test, scan, or attempt to access infrastructure based on this repository. No infrastructure address is intentionally published.

If this repository accidentally exposes sensitive information, please use GitHub's private vulnerability reporting feature if it is enabled. Otherwise, contact the repository owner through an existing private channel. Do not repost or further distribute the exposed value.

The repository intentionally excludes:

- credentials and tokens;
- private or recovery keys;
- notification topics;
- IP addresses and hostnames;
- raw logs and packet captures;
- personal identifiers;
- instructions for attacking unauthorized systems.
